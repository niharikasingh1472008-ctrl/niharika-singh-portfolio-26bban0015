DESIGN DIRECTION
Create an exceptionally polished, art-directed portfolio that feels like a boutique digital creative studio designed it over many iterations. It must be visually distinctive, editorial, sophisticated, clean, and memorable—not a generic AI-generated portfolio template.

Use a warm ivory, chalk white, deep forest green, muted olive, graphite, and restrained copper palette. Avoid the familiar purple-and-black AI aesthetic, neon gradients, excessive blue-purple glow, generic dashboard layouts, and overused startup landing-page patterns. Use strong typography, generous whitespace, carefully controlled contrast, precise alignment, beautiful grid systems, subtle borders, and thoughtful visual hierarchy.

Use high-quality, photorealistic visual compositions related to digital creativity, campaign art direction, typography, creative production, and AI-assisted visual experimentation. Prefer original, coherent visual assets over random stock imagery. Keep image crops intentional, aspect ratios consistent, and text legible. Do not distort images, faces, logos, typography, or visual assets. Never stretch images unnaturally.

MOTION AND INTERACTION
Implement smooth, restrained parallax scrolling in selected hero and image sections, elegant scroll-triggered reveals, subtle hover interactions, layered depth, refined page transitions, and a polished sticky navigation bar. Add a sophisticated glass UI treatment only where it improves usability—for example, a lightly translucent navigation panel or floating visual controls. Keep the overall design crisp rather than covering everything in glass effects.

Ensure motion is fluid, purposeful, and lightweight. Respect reduced-motion accessibility settings. Avoid excessive animation, scroll hijacking, distracting cursor effects, and effects that interfere with reading.

INFOGRAPHICS AND VISUAL STORYTELLING
Use custom icons, editorial project cards, a visual education timeline, a skill constellation or grouped skill map, and a clear contact panel. Use infographics only where they communicate real information. Do not invent statistics, campaign results, audience growth, conversion rates, client numbers, or skill proficiency. Each visual must support the content rather than act as decoration alone.

TECHNICAL REQUIREMENTS
Build a real, working website rather than a static design mockup. Use reusable components, clean code, responsive layouts, semantic HTML, accessible colour contrast, keyboard-friendly navigation, descriptive image alt text, and optimized assets. Test the design on desktop, tablet, and mobile. Ensure all buttons, anchor links, navigation items, and contact links work. Avoid horizontal overflow, broken images, layout shifts, console errors, and unreadable text. Optimize loading performance and SEO metadata. Use smooth scrolling without compromising accessibility.

Use only the personal information I provide. Do not invent projects, certificates, internships, achievements, work experience, qualifications, tools, or professional endorsements. Where information is missing, use clear editable placeholders and ask me to supply the details. Keep all claims truthful and appropriate for a student portfolio.
